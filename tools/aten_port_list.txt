# aten-port-gen curated op list — high-value tensor-algebra ports.
#
# Format:  tensor.<hnl-name> = aten::<name>[.<overload>]   [# seam: reason]
#
# The left side is the host-tensor op name (`tensor.<hnl-name>`); the
# right side pins the ATen schema the port claims provenance from. When
# several overloads share a name the pin selects the canonical one —
# merged drivers (marked "covers …" in src/ops/aten_kernels.rs) may
# implement sibling overloads too. `# seam:` entries declare the op but
# emit a stub that fails loudly — they are the honest "needs handwritten
# behavior" list, not implementations.
#
# Regenerate with:  cargo run --bin aten-port-gen
