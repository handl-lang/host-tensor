# Reference

## Public API

| item | what it is |
|---|---|
| `tensor.from_list`, `tensor.ones` | construction |
| `tensor.add`, `tensor.mul`, `tensor.div`, `tensor.matmul` | elementwise and matrix arithmetic |
| `tensor.reshape`, `tensor.concat` | shape manipulation |
| `tensor.conv`, `tensor.max_pool`, `tensor.batch_norm` | the layer ops |
| `*_backward` variants | gradients for every differentiable op |
| `tensor.derive` | run a backward pass given the upstream gradient |

## Crate

| crate | role |
|---|---|
| `handl-plugin-host-tensor` | host functions (`tensor.*`) |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
